## 🚀 Deployment

This site is deployed via **GitHub Pages** at:
```
https://jptpk5ry7g-max.github.io/prem-chat
```

### To Enable GitHub Pages:

1. Go to **Settings → Pages**
2. Set Source to `main` branch
3. Save

Your site will be live in ~1 minute!

## 💳 PayPal Setup

To enable payments:

1. Replace `emma@premchat.au` in `index.html` with your PayPal email
2. Update `YOUR_RETURN_URL` and `YOUR_CANCEL_URL` with your domain
3. Set up PayPal IPN notifications (optional, for tracking)

## 📝 Customization
